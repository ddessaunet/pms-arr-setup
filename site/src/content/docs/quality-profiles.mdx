A quality profile decides which releases Radarr or Sonarr will grab for a title, which one
it prefers, and whether a better one later replaces it. Every movie gets the default 4K HDR
profile unless you pick another; series always get 1080p.

[← Stack](/): every service's link and status.

This page is built from the repo: the profiles from `apps/recyclarr/recyclarr.yml`, the
size caps, defaults and upgrade rules from `stack/lib/arr-configure.sh`. It shows the repo
as of the last `task site:build`, not what Radarr has live: after changing a profile, run
`task recyclarr:sync` and `task arr:configure` too.
